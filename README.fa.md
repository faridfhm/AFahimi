# 🗓️ تقویم جلالی (TJalaliDatePicker)

یک کامپوننت بومی، پیشرفته، سبک و بدون وابستگی برای **نمایش، ورود، اعتبارسنجی و انتخاب تاریخ شمسی (جلالی)** در برنامه‌های VCL دلفی.

---

## 📋 معرفی

`TJalaliDatePicker` برای برنامه‌های ویندوزی VCL دلفی طراحی شده است. این کامپوننت هم به‌صورت **مستقل** و هم به‌صورت **متصل به داده (Data-Aware)** قابل استفاده است؛ بنابراین گزینه‌ای مناسب برای **نرم‌افزارهای تجاری دسکتاپ، سیستم‌های مبتنی بر پایگاه داده، و رابط‌های کاربری فارسی‌سازی‌شده** به‌شمار می‌آید.

## 🚀 قابلیت‌های منحصربه‌فرد

### 🔗 اتصال کامل به داده (Data-Aware)
این کامپوننت دارای یک لایه داخلی قدرتمند برای اتصال به `TDataSource` است. می‌تواند با فیلدهای پایگاه داده که به‌صورت متن (`VARCHAR`، `CHAR`) یا نوع‌های استاندارد تاریخ (`DATE`، `DATETIME`) ذخیره شده‌اند کار کند، در حالی که تجربه کاربری همچنان کاملاً **شمسی** باقی می‌ماند.

### 📦 جداسازی نمایش و ذخیره‌سازی
با استفاده از `ValueMode`، توسعه‌دهندگان می‌توانند نحوه ذخیره‌سازی تاریخ در پایگاه داده را انتخاب کنند:
- `vmJalali` : ذخیره‌سازی تاریخ به‌صورت متن شمسی
- `vmMiladi` : ذخیره‌سازی تاریخ به‌صورت متن میلادی یا مقدار استاندارد تاریخ

صرف‌نظر از نحوه ذخیره‌سازی، کامپوننت همیشه تاریخ را به‌صورت **شمسی و کاربرپسند** نمایش می‌دهد.

### ⌨️ ورود مستقیم با ماسک هوشمند
کاربر می‌تواند بدون باز کردن پنجره تقویم، تاریخ را مستقیماً تایپ کند. جداکننده‌های `/` هنگام تایپ به‌صورت خودکار درج می‌شوند تا ساختار تاریخ همواره معتبر باقی بماند.

### ✅ اعتبارسنجی دقیق هنگام خروج
هنگامی که کنترل فوکوس خود را از دست می‌دهد، تاریخ واردشده بر اساس قوانین تقویم شمسی اعتبارسنجی می‌شود (از جمله معتبر بودن شماره ماه، تعداد روزها و سال کبیسه). اگر مقدار واردشده نامعتبر باشد، کامپوننت آخرین تاریخ معتبر را بازیابی می‌کند.

### 🎨 رندر انعطاف‌پذیر آیکون بازشو
کامپوننت از محاسبات پویای هندسی برای ناحیه متن و دکمه بازشو استفاده می‌کند. در نتیجه، حتی اگر از آیکون‌های سفارشی بزرگ‌تر مانند `24x24` استفاده شود، تراز متن و دکمه همچنان صحیح باقی می‌ماند.

### 📅 پیمایش سریع چندنمایی
کاربر می‌تواند با کلیک روی عنوان ماه یا سال در سربرگ پنجره بازشو، به‌سرعت بین حالت‌های زیر جابه‌جا شود:
- 📅 **نمای روز**
- 🗓 **نمای انتخاب ماه**
- 📆 **نمای انتخاب سال / دهه**

### 🎯 فوکوس هوشمند اولیه
هنگام باز شدن پنجره تقویم، روز انتخاب‌شده به‌صورت خودکار در شبکه تقویم پیدا شده و فوکوس صفحه‌کلید روی آن قرار می‌گیرد؛ در نتیجه کاربر می‌تواند بلافاصله با کلیدهای جهت‌نما پیمایش را ادامه دهد.

## 💻 نحوه استفاده و نمونه کدها

### ۱. خواندن تاریخ شمسی انتخاب‌شده
```delphi
ShowMessage(JalaliDatePicker1.Date.AsString); // مثال: ۱۴۰۵/۰۴/۲۰
```

### ۲. تنظیم روی تاریخ روز
```delphi
JalaliDatePicker1.DateTime := Now;
```

### ۳. استفاده متصل به داده (Data-Aware)
اختصاص `DataSource` و `DataField` در زمان طراحی (Design-Time) یا اجرا (Run-Time):
```delphi
JalaliDatePicker1.DataSource := DataSource1;
JalaliDatePicker1.DataField := 'BirthDate';
```

### ۴. توابع کمکی تغییر تاریخ
```delphi
// اضافه کردن ۵ سال به تاریخ فعلی
JalaliDatePicker1.Date := JalaliDatePicker1.IncYear(5);

// اضافه کردن ۳ ماه
JalaliDatePicker1.Date := JalaliDatePicker1.IncMonth(3);

// اضافه کردن ۱۰ روز
JalaliDatePicker1.Date := JalaliDatePicker1.IncDay(10);
```

## 📚 مرجع خصوصیات

### 🔹 خصوصیات داده و مقدار

| خصوصیت | توضیح |
|--------|-------|
| `Date: TJalaliDate` | دسترسی به تاریخ شمسی فعلی به‌صورت یک رکورد شامل فیلدهایی مانند `Year`، `Month` و `Day`. |
| `DateTime: TDateTime` | تاریخ شمسی انتخاب‌شده را با نوع استاندارد `TDateTime` در دلفی همگام می‌کند. |
| `Value: string` *(فقط خواندنی)* | مقدار متنی نهایی کامپوننت را بر اساس `ValueMode` فعلی بازمی‌گرداند. نمونه: `1405/04/20` یا `2026/07/11` |
| `ValueMode: TDateValueMode` | نحوه ذخیره‌سازی یا نمایش تاریخ را مشخص می‌کند: `vmJalali` یا `vmMiladi` |
| `DataSource` | منبع داده مورد استفاده برای اتصال داده‌ای کامپوننت را مشخص می‌کند. |
| `DataField` | نام فیلد هدف در دیتاست متصل را تعیین می‌کند. |

### 🎨 خصوصیات ظاهری

| خصوصیت | توضیح |
|--------|-------|
| `Images: TCustomImageList` | یک لیست تصویر برای آیکون دکمه بازشو اختصاص می‌دهد. |
| `ImageIndex: TImageIndex` | شماره تصویر مورد استفاده از لیست تصاویر را مشخص می‌کند. |
| `DropIcon: TPicture` | امکان اختصاص مستقیم یک تصویر سفارشی به‌جای استفاده از ImageList را فراهم می‌کند. |
| `Font` | فونت متن ویرایشگر را کنترل می‌کند و در پنجره تقویم نیز اعمال می‌شود. |
| `Color` | رنگ پس‌زمینه ویرایشگر را تعیین می‌کند. |
