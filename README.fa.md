# 🗓️ تقویم جلالی

یک کامپوننت بومی، پایدار و سبک برای انتخاب تاریخ شمسی (جلالی) در برنامه‌های VCL دلفی.

---

## 📋 معرفی

`TJalaliDatePicker` یک کامپوننت پیشرفته، سبک و بدون وابستگی است که برای **نمایش، ورود، اعتبارسنجی و انتخاب تاریخ شمسی** در برنامه‌های ویندوزی VCL دلفی طراحی شده است.

این کامپوننت هم به‌صورت **مستقل** و هم به‌صورت **متصل به داده** قابل استفاده است؛ بنابراین گزینه‌ای مناسب برای **نرم‌افزارهای تجاری دسکتاپ، سیستم‌های مبتنی بر پایگاه داده، و رابط‌های کاربری فارسی‌سازی‌شده** به‌شمار می‌آید.

## 🚀 قابلیت‌های منحصربه‌فرد

### 🔗 اتصال کامل به داده

این کامپوننت دارای یک لایه داخلی قدرتمند برای اتصال به `TDataSource` است.  
می‌تواند با فیلدهای پایگاه داده که به‌صورت متن (`VARCHAR`، `CHAR`) یا نوع‌های استاندارد تاریخ (`DATE`، `DATETIME`) ذخیره شده‌اند کار کند، در حالی که تجربه کاربری همچنان کاملاً **شمسی** باقی می‌ماند.

### 📦 جداسازی نمایش و ذخیره‌سازی

با استفاده از `ValueMode`، توسعه‌دهندگان می‌توانند نحوه ذخیره‌سازی تاریخ در پایگاه داده را انتخاب کنند:

- `vmJalali` : ذخیره‌سازی تاریخ به‌صورت متن شمسی
- `vmMiladi` : ذخیره‌سازی تاریخ به‌صورت متن میلادی یا مقدار استاندارد تاریخ

صرف‌نظر از نحوه ذخیره‌سازی، کامپوننت همیشه تاریخ را به‌صورت **شمسی و کاربرپسند** نمایش می‌دهد.

### ⌨️ ورود مستقیم با ماسک هوشمند

کاربر می‌تواند بدون باز کردن پنجره تقویم، تاریخ را مستقیماً تایپ کند.  
جداکننده‌های `/` هنگام تایپ به‌صورت خودکار درج می‌شوند تا ساختار تاریخ همواره معتبر باقی بماند.

### ✅ اعتبارسنجی دقیق هنگام خروج

هنگامی که کنترل فوکوس خود را از دست می‌دهد، تاریخ واردشده بر اساس قوانین تقویم شمسی اعتبارسنجی می‌شود، از جمله:

- معتبر بودن شماره ماه
- معتبر بودن تعداد روزهای هر ماه
- رعایت قوانین سال کبیسه

اگر مقدار واردشده نامعتبر باشد، کامپوننت آخرین تاریخ معتبر را بازیابی می‌کند تا از ذخیره‌شدن داده نادرست جلوگیری شود.

### 🎨 رندر انعطاف‌پذیر آیکون بازشو

کامپوننت از محاسبات پویای هندسی برای ناحیه متن و دکمه بازشو استفاده می‌کند.  
در نتیجه، حتی اگر از آیکون‌های سفارشی بزرگ‌تر مانند `24x24` استفاده شود، تراز متن و دکمه همچنان صحیح و هماهنگ باقی می‌ماند.

### 📅 پیمایش سریع چندنمایی

کاربر می‌تواند با کلیک روی عنوان ماه یا سال در سربرگ پنجره بازشو، به‌سرعت بین حالت‌های زیر جابه‌جا شود:

- نمای روز
- نمای انتخاب ماه
- نمای انتخاب سال / دهه

این قابلیت، جابه‌جایی سریع میان ماه‌ها، سال‌ها و بازه‌های زمانی بزرگ‌تر را بسیار آسان می‌کند.

### 🎯 فوکوس هوشمند اولیه

هنگام باز شدن پنجره تقویم، روز انتخاب‌شده به‌صورت خودکار در شبکه تقویم پیدا شده و فوکوس صفحه‌کلید روی آن قرار می‌گیرد؛ در نتیجه کاربر می‌تواند بلافاصله با کلیدهای جهت‌نما پیمایش را ادامه دهد.

## 📚 مرجع خصوصیات

### 🔹 خصوصیات داده و مقدار

| خصوصیت | توضیح |
|--------|-------|
| `Date: TJalaliDate` | دسترسی به تاریخ شمسی فعلی به‌صورت یک رکورد شامل فیلدهایی مانند `Year`، `Month` و `Day`. برای خواندن یا تغییر جداگانه اجزای تاریخ بسیار کاربردی است. |
| `DateTime: TDateTime` | تاریخ شمسی انتخاب‌شده را با نوع استاندارد `TDateTime` در دلفی همگام می‌کند. با تغییر این خصوصیت، نمایش شمسی کامپوننت نیز به‌صورت خودکار به‌روزرسانی می‌شود. |
| `Value: string` *(فقط خواندنی)* | مقدار متنی نهایی کامپوننت را بر اساس `ValueMode` فعلی بازمی‌گرداند. نمونه: `1405/04/20` یا `2026/07/11` |
| `ValueMode: TDateValueMode` | نحوه ذخیره‌سازی یا نمایش تاریخ را مشخص می‌کند: `vmJalali` یا `vmMiladi` |
| `DataSource` | منبع داده مورد استفاده برای اتصال داده‌ای کامپوننت را مشخص می‌کند. |
| `DataField` | نام فیلد هدف در دیتاست متصل را تعیین می‌کند. |

### 🎨 خصوصیات ظاهری

| خصوصیت | توضیح |
|--------|-------|
| `Images: TCustomImageList` | یک لیست تصویر برای آیکون دکمه بازشو اختصاص می‌دهد. |
| `ImageIndex: TImageIndex` | شماره تصویر مورد استفاده از لیست تصاویر را مشخص می‌کند. |
| `DropIcon: TPicture` | امکان اختصاص مستقیم یک تصویر سفارشی به‌جای استفاده از ImageList را فراهم می‌کند. |
| `Font` | فونت متن ویرایشگر را کنترل می‌کند و در پنجره تقویم نیز اعمال می‌شود. |
| `Color` | رنگ پس‌زمینه ویرایشگر را تعیین می‌کند. |

## 🛠️ نصب

1. فایل پروژه پکیج را از پوشه `Packages/Delphi12` باز کنید.
2. پکیج را Build کنید.
3. پکیج Design-Time را در IDE دلفی نصب کنید.
4. در صورت نیاز، پوشه `Source` را به Library Path پروژه یا IDE اضافه کنید.
