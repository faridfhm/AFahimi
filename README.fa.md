# 🗓️ تقویم جلالی

یک کامپوننت بومی و پایدار برای انتخاب تاریخ شمسی (جلالی) در برنامه‌های VCL دلفی.

---

## 📋 نمای کلی

`TJalaliDatePicker` یک کامپوننت پیشرفته، سبک و بدون وابستگی برای نمایش، تایپ، اعتبارسنجی و انتخاب تاریخ شمسی در برنامه‌های ویندوزی VCL دلفی است.

این کامپوننت هم به‌صورت مستقل و هم به‌صورت متصل به پایگاه داده قابل استفاده است و برای برنامه‌های تجاری دسکتاپ، سیستم‌های مبتنی بر پایگاه داده و رابط‌کاربری فارسی‌سازی شده مناسب می‌باشد.

## 🚀 قابلیت‌های منحصربه‌فرد

### 🔗 اتصال کامل به داده

کامپوننت یک لایه اتصال داخلی قوی برای `TDataSource` فراهم می‌کند.  
می‌تواند با فیلدهای پایگاه داده که به‌صورت متن (`VARCHAR`، `CHAR`) یا نوع تاریخ استاندارد (`DATE`، `DATETIME`) ذخیره شده‌اند کار کند، در حالی که تجربه کاربری کاملاً شمسی باقی می‌ماند.

### 📦 جداسازی نمایش و ذخیره‌سازی

با استفاده از `ValueMode`، توسعه‌دهندگان می‌توانند نحوه ذخیره‌سازی مقدار در پایگاه داده را انتخاب کنند:

- `vmJalali`: ذخیره‌سازی متن تاریخ شمسی
- `vmMiladi`: ذخیره‌سازی متن تاریخ میلادی یا مقادیر استاندارد تاریخ

صرف‌نظر از فرمت ذخیره‌سازی، کامپوننت همواره تاریخ را به‌صورت شمسی و فارسی‌پسند به کاربر نمایش می‌دهد.

### ⌨️ تایپ مستقیم با ماسک زنده

کاربران می‌توانند تاریخ را بدون باز کردن پنجره بازشو به‌صورت دستی تایپ کنند.  
جداکننده‌های `/` به‌طور خودکار در حین تایپ درج می‌شوند تا ساختار تاریخ معتبر حفظ شود.

### ✅ اعتبارسنجی دقیق هنگام خروج

زمانی که کنترل فوکوس خود را از دست می‌دهد، تاریخ وارد شده بر اساس قوانین تقویم شمسی اعتبارسنجی می‌شود، از جمله:

- محدوده ماه معتبر
- تعداد روز معتبر برای هر ماه
- قوانین سال کبیسه

اگر ورودی نامعتبر باشد، کامپوننت آخرین تاریخ معتبر را بازیابی می‌کند تا از ذخیره‌سازی داده‌های خراب جلوگیری شود.

### 🎨 رندرینگ انعطاف‌پذیر آیکون بازشو

کامپوننت از محاسبات هندسی پویا برای ناحیه متن و دکمه بازشو پشتیبانی می‌کند.  
اگر از آیکون‌های سفارشی بزرگتر استفاده شود (مثلاً `۲۴x۲۴`)، تراز متن و دکمه به‌درستی حفظ می‌شود.

### 📅 پیمایش سریع چندنمایی

کاربران می‌توانند با کلیک روی عنوان ماه یا سال در هدر پنجره بازشو، به‌سرعت بین حالت‌های زیر جابه‌جا شوند:

- نمای روز
- نمای انتخاب ماه
- نمای انتخاب سال/دهه

این امکان، پیمایش سریع در بین ماه‌ها، سال‌ها و بازه‌های زمانی بزرگتر را فراهم می‌کند.

### 🎯 فوکوس هوشمند اولیه

هنگامی که پنجره بازشو باز می‌شود، کامپوننت به‌طور خودکار روز انتخاب‌شده را در شبکه تقویم پیدا کرده و فوکوس صفحه‌کلید را روی آن قرار می‌دهد و امکان پیمایش فوری با کلیدهای جهت‌نما را فراهم می‌کند.

## 📚 مرجع خصوصیات

### 🔹 خصوصیات داده و مقدار

| خصوصیت | توضیح |
|--------|-------|
| `Date: TJalaliDate` | دسترسی به تاریخ شمسی فعلی به‌صورت رکورد با فیلدهای جداگانه مانند `Year`، `Month` و `Day`. برای خواندن یا تغییر اجزای تاریخ شمسی به‌صورت جداگانه مفید است. |
| `DateTime: TDateTime` | همگام‌سازی تاریخ شمسی انتخاب‌شده با نوع استاندارد `TDateTime` دلفی. با تغییر این خصوصیت، نمایش تقویم شمسی به‌طور خودکار به‌روز می‌شود. |
| `Value: string` *(فقط خواندنی)* | مقدار نهایی متنی کامپوننت را بر اساس `ValueMode` فعلی بازمی‌گرداند. مثال‌ها: `۱۴۰۵/۰۴/۲۰` یا `۲۰۲۶/۰۷/۱۱`. |
| `ValueMode: TDateValueMode` | نحوه ذخیره یا نمایش مقدار تاریخ را تعیین می‌کند: `vmJalali` یا `vmMiladi`. |
| `DataSource` | مشخص‌کننده `TDataSource` برای اتصال به داده. |
| `DataField` | مشخص‌کننده نام فیلد هدف در مجموعه داده متصل. |

### 🎨 خصوصیات بصری

| خصوصیت | توضیح |
|--------|-------|
| `Images: TCustomImageList` | اختصاص یک لیست تصاویر برای آیکون دکمه بازشو. |
| `ImageIndex: TImageIndex` | مشخص‌کننده شاخص تصویر استفاده‌شده از لیست تصاویر اختصاص‌یافته. |
| `DropIcon: TPicture` | امکان اختصاص مستقیم یک تصویر سفارشی به‌جای استفاده از لیست تصاویر. |
| `Font` | کنترل فونت متن ویرایشگر که در تقویم بازشو نیز اعمال می‌شود. |
| `Color` | کنترل رنگ پس‌زمینه ویرایشگر. |

## 🛠️ نصب

1. فایل پروژه پکیج را از پوشه `Packages/Delphi12` باز کنید.
2. پکیج را Build کنید.
3. پکیج زمان طراحی را در IDE دلفی نصب کنید.
4. در صورت نیاز، پوشه `Source` را به مسیر کتابخانه خود اضافه کنید.
