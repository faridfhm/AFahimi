# تقویم جلالی برای دلفی

[English README](README.md)

یک کامپوننت انتخاب تاریخ جلالی (شمسی) بومی برای Delphi VCL که بدون وابستگی به کتابخانه‌های ثالث طراحی شده و با Delphi 12 کاملاً سازگار است.

## قابلیت‌ها

- انتخاب‌گر تاریخ جلالی (شمسی) بومی برای Delphi VCL
- سازگار کامل با Delphi 12
- بدون وابستگی به کتابخانه‌های جانبی
- قابل استفاده هم به‌صورت مستقل و هم به‌صورت Data-Aware
- اتصال هوشمند به `TDataSource`
- سازگار با فیلدهای متنی و فیلدهای تاریخ در پایگاه داده
- پشتیبانی از حالت ذخیره‌سازی منعطف با استفاده از `ValueMode`
- امکان تایپ مستقیم تاریخ با درج خودکار `/`
- اعتبارسنجی سخت‌گیرانه تاریخ هنگام خروج از فیلد
- پشتیبانی از آیکن سفارشی برای دکمه باز شدن تقویم
- تنظیم خودکار چیدمان برای اندازه‌های مختلف آیکن
- ناوبری سریع بین نماهای روز، ماه، سال و دهه
- تمرکز خودکار روی روز انتخاب‌شده هنگام باز شدن پنجره تقویم
- توابع کمکی افزایش تاریخ: `IncYear`، `IncMonth` و `IncDay`

## نصب

1. فایل پکیج موجود در پوشه `Packages` را در Delphi 12 باز کنید.
2. پکیج را Build و سپس Install نمایید.
3. سورس اصلی کامپوننت در پوشه `Source` قرار دارد.
4. پروژه نمونه برای مشاهده نحوه استفاده در پوشه `Demo` موجود است.

## پروژه نمونه

برای مشاهده عملکرد کامپوننت، پروژه نمونه موجود در پوشه `Demo` را اجرا کنید.
